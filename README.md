# Arduino Gyro-Based Robot 

## Overview

This project is an autonomous robot that uses an MPU6050 gyroscope to maintain direction and perform precise turns.

## Features

* Gyro-based straight-line correction
* Accurate 90° and 180° turns
* Modular movement functions
* Autonomous navigation sequence

## Hardware

* Arduino Uno
* MPU6050 Gyroscope
* Motor Driver
* DC Motors
